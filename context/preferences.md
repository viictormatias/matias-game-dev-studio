# Working preferences

- Conversation and hub docs: Brazilian Portuguese. Code, file names and engine
  identifiers stay in English.
- Engines: Unity first, Godot and Unreal when a project needs them. See
  `docs/hub.md`.
- Reports: shared Workspace styling, readable tabs, image enlargement and downloads.
- Changes: keep revisions together and record what was checked.
- Permissions: ordinary approvals by default.
- Restarts: ask before interrupting a running application or agent chat.
